Descripción e Introducción

El avance de la Ciencia de Datos y la apertura de APIs por parte de los principales exchanges de criptomonedas han democratizado el acceso a las finanzas cuantitativas. En este entrenamiento, desarrollaremos desde cero la estructura de un robot de trading automatizado (Algorithmic Trading Bot) utilizando Python.

Para este caso práctico, construiremos un entorno de backtesting y ejecución orientado al exchange Bybit, enfocándonos en una estrategia clásica de seguimiento de tendencia: el cruce de Medias Móviles Exponenciales (EMA). Utilizaremos librerías como pandas para la manipulación de datos espaciales y plotly para generar gráficos financieros altamente interactivos, sustituyendo el análisis visual tradicional por reglas matemáticas estrictas.

1. Arquitectura del Bot y Conexión a Bybit

El primer paso en el trading cuantitativo es establecer una conexión robusta con el mercado. En Python, la librería ccxt es el estándar de la industria, ya que proporciona una interfaz unificada para conectar con más de 100 exchanges, incluyendo Bybit. 

# Importación de librerías esenciales
import ccxt
import pandas as pd
import plotly.graph_objects as go
import time

# Inicialización del cliente de Bybit (Modo Testnet para seguridad)
exchange = ccxt.bybit({
    'apiKey': 'TU_API_KEY_AQUI',
    'secret': 'TU_SECRET_KEY_AQUI',
    'enableRateLimit': True,
})
exchange.set_sandbox_mode(True) # Activar entorno de pruebas

print("Conexión exitosa a Bybit. Balance disponible:", exchange.fetch_balance()['USDT']['free'])

2. Extracción y Limpieza de Datos (Klines)

Para que nuestro bot pueda analizar el mercado, necesitamos extraer el histórico de precios (Velas japonesas o OHLCV). Usaremos la función fetch_ohlcv y convertiremos los datos brutos en un DataFrame de Pandas para su análisis matemático. 

def obtener_datos(symbol, timeframe, limit=500):
    # Descargar velas (Open, High, Low, Close, Volume)
    velas = exchange.fetch_ohlcv(symbol, timeframe, limit=limit)
    
    # Convertir a DataFrame
    df = pd.DataFrame(velas, columns=['timestamp', 'open', 'high', 'low', 'close', 'volume'])
    
    # Formatear la fecha para hacerla legible
    df['timestamp'] = pd.to_datetime(df['timestamp'], unit='ms')
    df.set_index('timestamp', inplace=True)
    
    return df

# Obteniendo datos de Bitcoin a 1 hora
df_btc = obtener_datos('BTC/USDT', '1h')
print(df_btc.head())

3. Diseño de la Estrategia: Cruce de EMA's

Tal como expliqué en el capítulo de Análisis Técnico del Bitcoin, la señal de compra/venta más clásica surge del cruce de medias móviles. En código, esto se reduce a calcular la EMA rápida y la EMA lenta, y generar una columna booleana (1 o -1) cuando ambas se crucen. 

# Cálculo de Medias Móviles Exponenciales (EMA)
df_btc['EMA_9'] = df_btc['close'].ewm(span=9, adjust=False).mean()
df_btc['EMA_21'] = df_btc['close'].ewm(span=21, adjust=False).mean()

# Generación de Señales (Lógica Condicional)
df_btc['Signal'] = 0
df_btc.loc[df_btc['EMA_9'] > df_btc['EMA_21'], 'Signal'] = 1  # Señal de Compra (Bullish)
df_btc.loc[df_btc['EMA_9'] < df_btc['EMA_21'], 'Signal'] = -1 # Señal de Venta (Bearish)

# Detectar el momento exacto del cruce
df_btc['Posicion'] = df_btc['Signal'].diff()

6. Conclusiones y Siguientes Pasos

El desarrollo de un Bot en Python transforma el trading de una actividad emocional a un sistema determinístico. Sin embargo, un cruce de medias móviles es solo el bloque fundacional. En mis proyectos profesionales (como bot_red_neuronal.py o el optimizador_top10.py), integro modelos de Machine Learning para predecir falsos rompimientos, así como el Modelo de Markowitz para determinar el tamaño óptimo de la posición (Position Sizing) reduciendo la exposición al riesgo del algoritmo.
