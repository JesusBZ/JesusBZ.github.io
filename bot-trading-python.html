1. Introducción al Algorithmic Trading

El trading manual está perdiendo terreno. El estrés psicológico, la falta de disciplina y la incapacidad humana para analizar miles de datos en milisegundos hacen que la mayoría de los traders independientes pierdan dinero. La solución institucional es el Trading Cuantitativo: delegar las decisiones a modelos matemáticos e Inteligencia Artificial.

En esta masterclass, documentaré cómo estructurar un robot de trading en Python. Crearemos un portafolio equilibrado operando simultáneamente las tres criptomonedas líderes: Bitcoin (BTC), Ethereum (ETH) y Solana (SOL). Compararemos el rendimiento de 3 algoritmos automatizados frente a un portafolio de "Buy & Hold" para responder a la pregunta: ¿Puede nuestro código vencer al mercado?

2. Setup: Cómo conectar Python con Bybit

Utilizaremos la API de Bybit mediante la librería ccxt, que es el estándar de la industria para conexiones seguras. A continuación el código base para descargar las velas japonesas (Klines) en un DataFrame de Pandas: 
# Importación de librerías esenciales
import ccxt
import pandas as pd
import numpy as np

# 1. Conexión al exchange Bybit (Modo Testnet para simulación segura)
exchange = ccxt.bybit({
    'apiKey': 'TU_API_KEY_AQUI',
    'secret': 'TU_SECRET_KEY_AQUI',
    'enableRateLimit': True,
})
exchange.set_sandbox_mode(True)

# 2. Función para descargar histórico (Klines)
def obtener_datos_historicos(symbol, timeframe='1h', limit=1000):
    velas = exchange.fetch_ohlcv(symbol, timeframe, limit=limit)
    df = pd.DataFrame(velas, columns=['timestamp', 'open', 'high', 'low', 'close', 'vol'])
    df['timestamp'] = pd.to_datetime(df['timestamp'], unit='ms')
    return df.set_index('timestamp')

3. Modelos: Diseñando las 3 Estrategias (Portafolios)

Cada criptomoneda será operada por un algoritmo distinto dentro de nuestro script, iniciando con un capital virtual de $1,000 USD para cada una:

  • Portafolio 1 (BTC) - Tendencial (Cruce EMA): El bot calcula medias móviles. Compra cuando la tendencia es alcista (EMA 9 cruza hacia arriba a EMA 21) y vende para protegerse en caídas.
  • Portafolio 2 (ETH) - Reversión a la Media (RSI): El bot actúa como un "cazador de pánico". Compra en niveles de extrema sobreventa (RSI < 30) y vende en euforia (RSI > 70).
  • Portafolio 3 (SOL) - IA y Machine Learning: En lugar de indicadores fijos, entrenamos un modelo (Random Forest Classifier) que evalúa volatilidad y volumen para predecir matemáticamente la dirección de la siguiente vela.

La diferencia entre especular y hacer Trading Cuantitativo radica puramente en la gestión del riesgo. Un bot no tiene emociones y ejecuta su estrategia al milisegundo.
