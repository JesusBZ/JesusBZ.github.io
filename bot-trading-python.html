1. Introducción a la Inteligencia Artificial en Finanzas

El trading institucional ha evolucionado. Hoy en día, las decisiones ya no se toman mirando pantallas durante horas, sino mediante la ejecución de algoritmos de alta frecuencia y modelos de Machine Learning. En este proyecto técnico, documento el desarrollo de un bot automatizado en Python conectado al exchange Bybit.

Para demostrar la eficacia de las finanzas cuantitativas, he diseñado un motor de Backtesting Vectorizado. Simularemos una inversión idéntica de $1,000 USD en tres estrategias diferentes (desde indicadores clásicos hasta predicciones con Redes Neuronales) para visualizar cómo la Inteligencia Artificial gestiona el riesgo y optimiza los retornos frente a la volatilidad del Bitcoin.

2. Conexión de API y Extracción de Datos

Utilizamos la librería ccxt para la comunicación segura con la API, y pandas para transformar los datos crudos del mercado en tensores matemáticos listos para ser ingeridos por modelos de IA. 

# Importación del stack científico financiero
import ccxt
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestClassifier

# Conexión al exchange mediante API Keys encriptadas (Entorno de pruebas)
exchange = ccxt.bybit({
    'apiKey': 'API_KEY_OCULTA',
    'secret': 'SECRET_KEY_OCULTA',
    'enableRateLimit': True
})

def obtener_dataset_historico(symbol='BTC/USDT', timeframe='1h'):
    # Descarga OHLCV (Open, High, Low, Close, Volume)
    velas = exchange.fetch_ohlcv(symbol, timeframe, limit=1000)
    df = pd.DataFrame(velas, columns=['timestamp', 'open', 'high', 'low', 'close', 'volume'])
    df['timestamp'] = pd.to_datetime(df['timestamp'], unit='ms')
    df.set_index('timestamp', inplace=True)
    return df

3. Diseño de los 3 Portafolios (Estrategias)

Para nuestro backtesting, configuramos el motor con un balance inicial de $1,000 USD y aplicamos tres modelos matemáticos distintos al histórico del Bitcoin:

  • Portafolio 1 (Tendencial - Cruce EMA): Estrategia clásica basada en el cruce de la Media Móvil Exponencial rápida (9 periodos) contra la lenta (21 periodos). Excelente en mercados alcistas, sufre en mercados laterales.
  • Portafolio 2 (Reversión a la Media - RSI): Utiliza el Índice de Fuerza Relativa (RSI). Compra en niveles de sobreventa (<30) y vende en sobrecompra (>70).
  • Portafolio 3 (Inteligencia Artificial - Random Forest): En lugar de indicadores fijos, entrenamos un modelo de Machine Learning que analiza 15 features simultáneas (Volatilidad, Momentum, Volumen) para predecir la dirección de la siguiente vela. Evita operaciones de alto riesgo (Drawdown minimizado).

6. Conclusiones y Gestión de Riesgo

Como se observa en los modelos, los indicadores tradicionales (Portafolios 1 y 2) pueden ser rentables, pero presentan caídas abruptas (Drawdowns) cuando el mercado cambia de régimen bruscamente.

La implementación de Inteligencia Artificial (Portafolio 3) no solo maximiza el Retorno de Inversión (ROI), sino que actúa como un escudo protector del capital (Risk Management). Al combinar algoritmos predictivos con teorías de optimización de carteras (como la Frontera Eficiente de Markowitz), transformamos el trading en un modelo de negocio científico, escalable y gestionado puramente por datos.
