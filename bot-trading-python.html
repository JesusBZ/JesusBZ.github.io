1. Perspectiva Macro: Bar Chart Race (Top 10 Criptos en 5 años)

Antes de diseñar un algoritmo, el Quant (Analista Cuantitativo) debe entender el ecosistema. Operar monedas sin liquidez destruye cualquier estrategia algorítmica debido al Slippage (deslizamiento de precios). Dale "PLAY" a la siguiente animación para observar cómo ha mutado la dominancia del mercado y por qué para este robot seleccionamos exclusivamente la cesta de mayor tracción institucional: BTC, ETH y SOL.


2. Ingeniería de Datos: Conexión API Bybit y Heatmap de Correlación

Para que nuestro bot pueda leer el mercado, extraemos el historial completo mediante la librería ccxt conectada al entorno Testnet de Bybit. 

# Inicialización del Robot Quant (Python)
import ccxt
import pandas as pd
import pandas_ta as ta # Librería avanzada de indicadores
from sklearn.ensemble import RandomForestClassifier

# Conexión Segura al Exchange Bybit
exchange = ccxt.bybit({
    'apiKey': 'TU_API_KEY_AQUI',
    'secret': 'TU_SECRET_KEY_AQUI',
    'enableRateLimit': True
})
exchange.set_sandbox_mode(True)

# Extracción de Datos (3 Años de Velas Diarias)
activos = ['BTC/USDT', 'ETH/USDT', 'SOL/USDT']
df_mercado = pd.DataFrame()

for coin in activos:
    velas = exchange.fetch_ohlcv(coin, timeframe='1d', limit=1095)
    df_mercado[coin] = pd.DataFrame(velas)[4] # Extraemos solo el Precio de Cierre (Close)

¿Por qué estas 3 monedas? La Teoría Moderna de Portafolios (Markowitz) dicta que debemos diversificar. El siguiente Mapa de Calor de Correlación (Heatmap) generado por el bot demuestra que, aunque el mercado cripto está altamente correlacionado, SOL y BTC tienen desviaciones suficientes para permitir que la Inteligencia Artificial cubra riesgos (Hedging) durante anomalías del mercado.


3. Diseño Matemático: Las 3 Estrategias (Portafolios)

Para nuestro Backtest, inyectamos $1,000 USD a cada modelo. El capital se reparte equitativamente en la cesta (BTC, ETH, SOL) y se aplican 3 metodologías distintas, descontando automáticamente el 0.05% de comisión del exchange en cada transacción.

  • Portafolio 1 (Momentum - EMA Cross): Un clásico. Opera a favor de la inercia calculando el cruce de la Media Móvil Exponencial rápida (9) sobre la lenta (21). Si el mercado cae, se refugia en Dólares (USDT).
  • Portafolio 2 (Reversión a la Media - RSI): Calcula las ineficiencias y desvíos estándar. Compra caídas extremas (RSI < 30) apostando al rebote algorítmico.
  • Portafolio 3 (Machine Learning - Random Forest): La joya de la corona. En lugar de fórmulas rígidas, entrenamos a una IA para evaluar el Order Book Imbalance, Volatilidad y Volumen simultáneo. El modelo asigna una probabilidad matemática de rentabilidad al día de mañana y sólo dispara la orden si la certeza supera el 65%.

5. Gestión de Riesgo Institucional: Análisis de Drawdown

El Max Drawdown es la pesadilla de todo fondo de inversión: mide la peor caída de capital desde un pico histórico. Mientras que el mercado cripto ha forzado a los inversores a soportar colapsos de hasta el -70% de sus cuentas, observa en la gráfica inferior cómo el modelo de Machine Learning corta las pérdidas a tiempo, preservando la liquidez para comprar más barato después.
