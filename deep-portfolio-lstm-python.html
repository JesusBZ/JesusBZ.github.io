3. De la Media-Varianza Estática a Deep Portfolio Optimization con Redes Neuronales LSTM

En la formulación clásica de Harry Markowitz (1952) y William Sharpe (1964), el vector de pesos óptimos del Portafolio Tangente \(\mathbf{w}^* \in \Delta^N\) se obtiene resolviendo un problema de optimización estática donde el vector de retornos esperados \(\boldsymbol{\mu}\) y la matriz de covarianza \(\boldsymbol{\Sigma}\) se asumen constantes en el tiempo:

$$\max_{\mathbf{w} \in \mathbb{R}^N} \mathcal{S}(\mathbf{w}) = \frac{\mathbf{w}^\top \boldsymbol{\mu} - r_f}{\sqrt{\mathbf{w}^\top \boldsymbol{\Sigma} \mathbf{w}}} \quad \text{sujeto a} \quad \sum_{i=1}^{N} w_i = 1, \quad w_i \ge 0 \; \forall i \in \{1,\dots,N\}$$

En los mercados financieros, tanto las correlaciones cruzadas como las primas por riesgo presentan cambios estructurales de régimen (no estacionariedad y heterocedasticidad condicional). El enfoque de Deep Portfolio Optimization (Zhang, Zohren & Roberts, Journal of Financial Data Science, 2020) sustituye la estimación estática en dos etapas por una Red Neuronal Recurrente de Memoria a Largo y Corto Plazo (LSTM — Long Short-Term Memory) que mapea directamente la secuencia temporal de tensores de mercado \(\mathbf{X}_{t-L:t} \in \mathbb{R}^{L \times N \times F}\) hacia el vector de asignación dinámica \(\mathbf{w}_t\).

En cada corte temporal \(t\), cada celda recurrente LSTM actualiza su estado de memoria interna \(\mathbf{c}_t\) y su estado oculto \(\mathbf{h}_t\) mediante tres compuertas no lineales diferenciables (compuerta de olvido \(\mathbf{f}_t\), compuerta de entrada \(\mathbf{i}_t\) y compuerta de salida \(\mathbf{o}_t\)):

$$\begin{aligned} \mathbf{f}_t &= \sigma\left(\mathbf{W}_f \mathbf{x}_t + \mathbf{U}_f \mathbf{h}_{t-1} + \mathbf{b}_f\right) \quad &\text{(Compuerta de Olvido / Régimen)} \\ \mathbf{i}_t &= \sigma\left(\mathbf{W}_i \mathbf{x}_t + \mathbf{U}_i \mathbf{h}_{t-1} + \mathbf{b}_i\right), \quad \tilde{\mathbf{c}}_t = \tanh\left(\mathbf{W}_c \mathbf{x}_t + \mathbf{U}_c \mathbf{h}_{t-1} + \mathbf{b}_c\right) \quad &\text{(Compuerta de Entrada y Candidato)} \\ \mathbf{c}_t &= \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t \quad &\text{(Estado de Memoria Celular a Largo Plazo)} \\ \mathbf{o}_t &= \sigma\left(\mathbf{W}_o \mathbf{x}_t + \mathbf{U}_o \mathbf{h}_{t-1} + \mathbf{b}_o\right), \quad \mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t) \quad &\text{(Estado Oculto Latente)} \end{aligned}$$

Para satisfacer analíticamente las restricciones de presupuesto (\(\sum_{i=1}^N w_{i,t} = 1\)) y de solo posiciones en largo (\(w_{i,t} \ge 0\)), la capa de salida aplica una transformación Softmax con temperatura adaptativa \(\tau\) combinada con un vector de paridad de riesgo condicional (\(\mathbf{w}_t^{\text{inv-vol}}\)), calibrando los parámetros \(\theta\) de extremo a extremo para minimizar el negativo del Ratio de Sharpe-Sortino Diferenciable neto de costos de transacción (\(c_{\text{tx}} = 4\text{ bps}\)):

$$w_{i,t}(\theta) = (1 - \lambda)\frac{\exp(\tau z_{i,t})}{\sum_{j=1}^{N} \exp(\tau z_{j,t})} + \lambda w_{i,t}^{\text{inv-vol}}, \qquad \mathcal{L}(\theta) = -\left(0.60 \cdot \widehat{\text{Sharpe}}(\mathbf{r}_p) + 0.40 \cdot \widehat{\text{Sortino}}(\mathbf{r}_p)\right) + \gamma \|\theta\|_2^2$$

Paso 4.3. Ingeniería de Características Tensoriales y Red Neuronal DeepPortfolioLSTM en PyTorch

Para cada activo \(i \in \{1,\dots,6\}\) se construye un vector de 8 factores cuantitativos libres de sesgo de anticipación (Momentum a 21, 63, 126 y 252 días, volatilidad realizada inversa de 21 días, Rolling Sharpe de 6 y 12 meses, y distancia logarítmica a la media móvil de 200 sesiones), estandarizados transversalmente en cada fecha \(t\), definiendo el módulo neuronal recurrente en PyTorch: 

import torch
import torch.nn as nn
import torch.optim as optim

class DeepPortfolioLSTM(nn.Module):
    """
    Arquitectura de Red Neuronal Recurrente LSTM para Asignación Dinámica de Carteras.
    Recibe tensores (Batch, Lookback_Window, N_Assets * N_Features) y genera
    pesos óptimos w_t >= 0 con suma unitaria que maximizan el Ratio de Sharpe-Sortino.
    """
    def __init__(self, n_assets: int = 6, n_features: int = 8, hidden_dim: int = 32):
        super().__init__()
        self.n_assets = n_assets
        self.n_features = n_features
        self.lstm = nn.LSTM(
            input_size=n_assets * n_features,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True,
            dropout=0.15
        )
        self.layer_norm = nn.LayerNorm(hidden_dim)
        self.head = nn.Linear(hidden_dim, n_assets)
        self.temperature = nn.Parameter(torch.tensor(0.85))

    def forward(self, x_seq: torch.Tensor, inv_vol_anchor: torch.Tensor) -> torch.Tensor:
        # x_seq: (Batch, Seq_Len, N_Assets * N_Features)
        lstm_out, _ = self.lstm(x_seq)
        h_last = self.layer_norm(lstm_out[:, -1, :])
        logits = self.head(h_last) * torch.exp(torch.clamp(self.temperature, -1.0, 1.8))
        w_neural = torch.softmax(logits, dim=-1)
        # Combinación convexa con vector de mínima varianza / volatilidad inversa
        w_final = 0.80 * w_neural + 0.20 * inv_vol_anchor
        return w_final


def differentiable_sharpe_sortino_loss(
    weights: torch.Tensor,
    next_returns: torch.Tensor,
    rf_daily: float = 0.025 / 252.0,
    tx_cost_bps: float = 0.0004
) -> torch.Tensor:
    """
    Función de pérdida diferenciable end-to-end:
    Maximiza (0.60 * Ratio de Sharpe + 0.40 * Ratio de Sortino) neto de costos de rotación.
    """
    port_ret = torch.sum(weights * next_returns, dim=1)
    turnover = torch.sum(torch.abs(weights[1:] - weights[:-1]), dim=1)
    port_ret_net = port_ret.clone()
    port_ret_net[1:] = port_ret_net[1:] - turnover * tx_cost_bps

    excess_ret = port_ret_net - rf_daily
    ann_excess = torch.mean(excess_ret) * 252.0
    ann_vol = torch.std(port_ret_net) * torch.sqrt(torch.tensor(252.0)) + 1e-6
    sharpe = ann_excess / ann_vol

    downside = torch.clamp(excess_ret, max=0.0)
    downside_vol = torch.sqrt(torch.mean(downside ** 2) * 252.0) + 1e-6
    sortino = ann_excess / downside_vol

    return -(0.60 * sharpe + 0.40 * sortino)
