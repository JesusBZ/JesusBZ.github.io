# Sistemas de Trading Algorítmico Cuantitativo y Arquitectura Híbrida de 3 Capas en Python (`v4_hybrid_3tier`)

Arquitectura cuantitativa multi-estrategia en Python con conciliación directa frente a libros públicos de mercado (**OKX API v5**, **Bybit API v5**, **KuCoin API v1** y **Kraken REST**), etiquetado causal de Triple-Barrera, detección de regímenes mediante Modelos de Mezcla Gaussiana (**GMM**), análisis de flujo (**OBV** y **Open Interest SWAP**) y cadena criptográfica de integridad **SHA-256**:

1. **Backtesting Walk-Forward Causal de 5 Años (Base `$1,000.00 USD`):** Evaluación comparativa fuera de muestra sobre una canasta de 8 criptoactivos de alta liquidez (`BTC`, `ETH`, `SOL`, `BNB`, `XRP`, `ADA`, `AVAX`, `LINK`) mediante cuatro metodologías:
   - **Markowitz Media-Varianza con Contracción de Ledoit-Wolf (`SLSQP`) y Filtro Tendencial**
   - **Modelo Econométrico `GJR-GARCH(1,1,1)` Asimétrico (*Skewed Student-t* + Objetivo de Volatilidad)**
   - **Optimización Estocástica de Monte Carlo (`Min-CVaR 95%`)**
   - **Red Neuronal Profunda Adiestrada (`Ensamble MLP` Regularizado con Parada Temprana y Salida `ATR`)**
2. **Arquitectura Híbrida Supervisora de 3 Capas (`v4_hybrid_3tier`):**
   - **Capa 1 · Inteligencia Predictiva y Flujo (`15` Variables Ortogonales):** Etiquetado causal **Triple-Barrera** (`TP 1.80x ATR` vs `SL 1.40x ATR` vs `Espera` neto de comisiones sin fuga futura), pendiente normalizada de **OBV**, distancia a `EMA 200`, canal mín-máx, fuerza relativa y correlación frente a `BTC`, aceleración `RSI` y **Open Interest perpetuo SWAP** (`OKX/Bybit`).
   - **Capa 2 · Detector Causal de 4 Regímenes (`GMM`) y Ensemble 3-Clases:** Clasifica el entorno en `TENDENCIA_ALCISTA`, `MERCADO_LATERAL`, `TENDENCIA_BAJISTA` o `ALTA_VOLATILIDAD` y combina cuatro modelos con purga temporal (`32` muestras) y gobernanza *Campeón vs. Retador*: **44% `HistGradientBoostingClassifier`** + **26% `MLP(32, 16)`** + **15% `LogisticRegression`** + **15% Prior de Régimen `GMM`** produciendo probabilidades calibradas de Alza, Lateral y Baja.
   - **Capa 3 · Guardián Independiente de Capital y Riesgo (`RiskGatekeeper`):** Autoridad de veto independiente sobre todas las estrategias (`0.25%–0.55%` riesgo por operación modulado por régimen), interruptor de emergencia (`Kill Switch` en `-8.5%` de drawdown), límite de pérdida diaria (`-2.0%`), filtro de liquidez (`spread <= 12 bps`, divergencia OKX/Bybit `<= 45 bps`) y ratio Riesgo/Beneficio mínimo (`>= 1.50`).
3. **Sistema Autónomo de 4 Algoritmos Especializados (`$1,000.00 USD` de Base cada uno):**
   - **BOT A — Microtrading Intradía por Impulso, Flujo OBV y Régimen GMM (`15m / 1H`):** Alineación `EMA 9 / 21 / 55` + `EMA 200`, fuerza `ADX 1H >= 20`, filtro `ATR/Precio >= 0.42%`, `OBV`, `ROC(10)` y volumen (`>= 1.08x SMA20`), con riesgo base de `0.50%` modulado por régimen (`0.25%–0.55%`), `SL 1.55x ATR`, toma parcial `45%` en `1.40x ATR`, `TP 3.10x ATR`, *trailing* causal y corte diario `-2.0%`.
   - **BOT B — Decisión Sistemática Diaria Adaptativa por Régimen (`1D`):** Canal `SMA 20 / EMA 50`, `Bollinger %B`, `MACD(12,26,9)`, `ADX(14)`, flujo `OBV` y fuerza relativa `BTC`, optimización `Markowitz / GJR-GARCH` con penalización `L1`, tope dinámico de exposición por régimen `GMM` y salida *Chandelier* (`2.30x ATR`).
   - **BOT C — Largos Posicionales y Contratos a Futuros SWAP con Open Interest (`4H SWAP`):** Estructura direccional `EMA 21/55`, `Bollinger %B`, `ROC(24)`, `ADX/DI`, ratio **Open Interest / Volumen**, flujo `OBV`, *carry* de financiamiento cada `8h`, reducción progresiva de riesgo bajo drawdown y protección `SL 2.85x ATR` en cada vela `4H`.
   - **BOT D — Ensemble Supervisado Triple-Barrera y Régimen GMM (`4H`):** Opera señales del Ensemble `3-Clases` (`HGB + MLP + LogReg + GMM`), fuerza relativa positiva frente a `BTC`, confirmación `OBV`/volumen, reentrenamiento con gobernanza *Campeón vs. Retador* cada `60` barras y veto del Guardián Independiente de Riesgo.
4. **Certificación y Verificación (`30` Pruebas Unitarias):** Libro mayor persistente encadenado con `SHA-256` (`bot_state_ledger.json`) y batería de `30` verificaciones determinísticas (`tests/test_bots_rules.py`).
